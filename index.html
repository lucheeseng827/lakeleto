Stays on your machine

No account, no server in the path. Buckets are read with your own credentials, straight to your laptop.

Read-only

SQL is SELECT only and database connections can't write. Exports are new files.

Works offline

The UI is inside the binary. No CDN, no fonts to fetch. Runs on a plane or an air-gapped box.

Agents too

lakeleto mcp lets Claude, Cursor or any MCP client read your tables, capped and confined to a folder.

Measured, one command at a time.

Each bar is one command typed in a terminal, start to exit, median of five runs on a warm file cache. Lakeleto answers "what is this file?" fastest and on a CSV it leads. On a full scan of a 20-million-row Parquet file, DuckDB is about twice as fast. Lakeleto and DuckDB finish every task in under 0.3 s, using a fraction of the memory of loading a DataFrame.

Reading the bars

Bars are time, scaled to the slowest tool in each task. The label is the median time, then the process's peak working set. Shorter is better on both.

Polars and pandas are timed as Python one-liners, so roughly 0.2–0.3 s of each is starting Python and importing the library. In a notebook that's paid once. From a terminal it's paid every time.

Method, versions and exact commands

Run 2026-11-04 on one laptop: AMD Ryzen 9 8945HS (8 cores, 16 threads), 93 GiB RAM, NVMe SSD, Windows 11. Lakeleto 0.4.0 (release build, release feature set), DuckDB CLI 1.4.1, Polars 1.34.0, pandas 2.3.3 with pyarrow 21.0.0, Python 3.12. Each command ran once to warm the cache, then five times; the median is shown. Memory is the peak working set Windows records for the process. All four tools returned the same counts and sums.

Data: 20,000,000 orders-shaped rows (10 columns: ids, strings, doubles, a boolean, a timestamp) generated by DuckDB with a fixed seed and written as Snappy Parquet (463 MiB), and 2,000,000 of the same as CSV (145 MiB). One machine and one data shape. Your numbers will differ, so run it yourself: gen.py, bench.py, raw results.

lakeleto schema orders_20m.parquet
lakeleto head orders_20m.parquet -n 10
lakeleto query "SELECT city, count(*) AS n, round(sum(amount_usd), 2) AS revenue
  FROM t GROUP BY city ORDER BY revenue DESC" --file orders_20m.parquet
lakeleto query "SELECT order_id, city, amount_usd FROM t WHERE tier = 'enterprise'
  AND NOT is_refunded ORDER BY amount_usd DESC LIMIT 10" --file orders_20m.parquet

duckdb -c "DESCRIBE SELECT * FROM 'orders_20m.parquet'; SELECT count(*) FROM 'orders_20m.parquet';"

Who it's for.

Lakeleto is an early release, v0.4.1. It's built for these three cases.

Data engineers

You live in a terminal and want to see a table before you build on it. lakeleto schema, head and profile --fast answer in one line, in CI too.

Analysts who don't code

You have a Parquet file and no Python. Install, click the file, scroll, filter, export to CSV. SQL is there when you want it.

Teams that can't upload

Customer records, regulated data, air-gapped boxes. Nothing leaves the machine, and --root keeps it to one folder.

Need to transform, join across warehouses or write results back? Use DuckDB or Polars. Lakeleto hands you Parquet or Arrow (-o parquet, -o arrows) to pass along.

Before you download.

How finished is it?

It's v0.4.1, an early release. The grid, schema, profile, SQL, export, every reader above and the database connectors work today, and the maintainers use it daily. Expect rough edges, and file them.

What does it cost?

Nothing. The tool is Apache-2.0 and stays that way. A hosted team edition is on the roadmap. It isn't available, and nothing on this page depends on it.

Files bigger than my memory?

Yes. The grid reads a window at a time and Parquet by row group. Sorts and filters run in the SQL engine over the whole file. Iceberg and Delta tables are loaded into memory for that.

Why does my OS warn me on first launch?

No Authenticode certificate or Apple notarization yet. On Windows: More info → Run anyway. On macOS: right-click → Open once. Every release carries a cosign signature, a SHA-256 and SLSA provenance you can check instead.
